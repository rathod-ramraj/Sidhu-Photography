# 📸 Sidhu Photography Portfolio

A modern, high-performance photography portfolio website built for **Sidhu Photography**, showcasing timeless wedding stories, editorial portraits, pre-wedding journeys, cultural celebrations, and lifestyle imagery.

## 🌟 Features

- **Brand Story & Aesthetics**: Dedicated hero, biography, and fine-art photography presentation.
- **Photography Services**: Showcases specialized offerings (Weddings, Pre-Weddings, Portraits, Events, Fashion, Lifestyle, Candid, Drone, and Fine-Art Albums).
- **Interactive Galleries**: Responsive project showcases with smooth GSAP animations and parallax transitions.
- **Detailed Case Studies**: High-resolution image view, equipment & gear breakdowns, and creative direction notes.
- **Direct Contact**: Quick booking links and sticky email integration (`Ajmeranaresh391@gmail.com`).
- **Smooth Navigation & Motion**: Powered by Lenis smooth scroll and GSAP ScrollTrigger.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP, @gsap/react, ScrollTrigger
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed

### Installation

```bash
npm install --legacy-peer-deps
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm run start
```
